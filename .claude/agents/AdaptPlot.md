# Вхідні данні
У теці `$CLAUDE_PROJECT_DIR/plots/current/` розташовано поточний сюжетний буклет що розробляється. Там твоя робоча тека. 
Конкретно файл `plot.json` маєш змінити значення параметру `"story"` з урахуванням персонажів.  

# Загальне Завдання
Адаптувати сюжет враховуючи передісторію персонажів з опису. Якщо сюжет перестає відповідати схемі конфліктів, конфлікти треба передивитись також. 
Зауваж що ім'я та стать персонажів мають співпадати: опис персонажа це джерело істини - всі інші згадування цього персонажа мають відповідати його опису щодо ім'я та статі. 

Вимоги до сюжету описані у `$CLAUDE_PROJECT_DIR/.claude/agents/instructions/plot_guide.md`
Приклади сюжетів у теці `$CLAUDE_PROJECT_DIR/.claude/agents/samples/` для різних жанрів.
Обов'язково притримуйся жанру оригінального сюжету. 
Не змінюй кількість персонажів і не плутай їх імена.

# Результат
Результат це сюжет що ти його маєш внести у структуру файлу `plot.json` - у параметр `story`-саму історію сюжету. 
У параметр `conflicts` - конфлікти, якщо треба.
У параметр `facts` - факти. Їх теж варто за потреби оновити у відповідності до сюжету.
