# Буклет із сюжетом

Три панелі на бік, два боки, A4 landscape (297×210 мм), два згини.

```
бік 1 (зовні):  [ ФАКТИ ] [ ПЕРСОНАЖІ ] [ ТИТУЛ ]
бік 2 (всере.): [ КОНФЛІКТИ ] [ ——— СЮЖЕТ (2/3) ——— ]
```

## Вхід
У файлі `$CLAUDE_PROJECT_DIR/plots/current/plot.json` лежить структура готового сюжету

| тег | значення |
|---|---|
| `genre` | Романтичний, Детективний, Драматичний або Християнський |
| `characters_count` | кількість персонажів |
| `logline`| Короткий тизер сюжету |
| `story` | історія, тіло сюжету | 
| `title` | Назва сюжету |
| `characters` | список персонажів з їх описами |
| `conflicts`  | конфлікти між персонажами - напрямок на суть конфлікту |
| `facts` | Факти що мають персонажі з назвами і їх значенням у контексті сюжету |

Скопіюй цей файл собі у робочу теку:
 ```bash
 cp $CLAUDE_PROJECT_DIR/plots/current/plot.json plot.json
 ```
 
## Хід роботи
Скіл самодостатній: усе — скрипти, шрифтові стилі, логотипи, ключі Midjourney,
готові буклети — лежить у теці скіла. 
**Спершу перейди в неї, далі всі шляхи відносні від неї:**

```bash
cd .claude/skills/plot-booklet
```

**1. Створи робочу теку** `out/NAME/` (NAME — `title` латиницею, без пробілів):

```bash
mkdir -p out/NAME/art
```

**2. Перевір правила** — це швидко і ловить структурні помилки:

```bash
python3 scripts/validate_plot.py out/NAME/plot.json
```

Виправ усі `ПОМИЛКА:` перед тим, як рендерити.

**3. Ілюстрації.** Потрібні дві: `art/cover.png` (титульна, 2:3) і
`art/inner.png` (до конфліктів, 1:1). Генеруються через Midjourney за
допомогою сервісу GptProto — деталі промпту й виклику в `references/midjourney.md`.

**Якщо GptProto недоступний** — скажи про це користувачу і збери буклет
із заглушкою, щоб було видно верстку:

```bash
python3 scripts/placeholder_art.py out/NAME/art/cover.png --ar 2:3 --seed "NAME"
python3 scripts/placeholder_art.py out/NAME/art/inner.png --ar 1:1 --seed "NAME2"
```

Заглушка — тільки для перевірки верстки, у фінальний буклет вона не йде.
Обов'язково попередь, що ілюстрації в PDF тимчасові.

**5. Збери PDF:**

```bash
python3 scripts/build_booklet.py out/NAME/plot.json --out out/NAME/NAME
```

Скрипт сам виводить палітру з титульної ілюстрації, підганяє кегль під висоту
панелей і кладе поруч `_preview_1.png` / `_preview_2.png`.

**6. Прочитай звіт** у stderr — `панелі (заповненість / кегль)`:

| що каже | що робити |
|---|---|
| `!! текст обрізано` | скороти текст цієї панелі, це єдиний вихід |
| `! кегль стиснуто до N%` | текст задовгий; при N < 90% обов'язково скороти |
| `~ ілюстрацію знято` | конфліктів забагато для колонки — скороти позиції |
| `~ story заповнено лише N%` | розшир сюжет (див. нижче про довжину) |

**7. Подивись обидва прев'ю очима** через Read. Перевір: назва не переносить
слово навпіл, ілюстрація не обрізала обличчя, текст читабельний на тлі,
логотип жанру правильний.

## Палітра

Кольори беруться з титульної ілюстрації (`scripts/palette.py`, k-means по
зменшеній копії) і роздаються на ролі: `page_bg` (поля), `panel_bg` (тло панелей),
`ink`, `heading`, `rule`, `frame` (рамка ілюстрації). Світлий чи темний варіант
обирається за середньою яскравістю зображення.

**Християнські сюжети — виняток:** поля завжди білі, тло панелей RGB(235,230,220).
Це зашито у `palette.CHRISTIAN` і застосовується автоматично за `genre`.

Якщо автоматична палітра не подобається — впиши готовий блок `"palette": {...}`
у `plot.json`, він має пріоритет.

## Довжина сюжету

Блок сюжету — це 2/3 сторінки A4 landscape. Заміряно на реальних збірках:

| кегль | вміщується |
|---|---|
| 11pt (типово) | **1400–1800 символів** |
| 9pt | ~2100–2700 |
| 8pt | ~2700–3500 (щільність зразкових буклетів) |

Розкид у кожному рядку — через діалоги: репліка займає цілий рядок, хай там
три слова. Сюжет на самих коротких репліках вміщується вдвічі гірший за
той самий обсяг суцільної прози. **Рахуй рядки, а не символи.**

За замовчуванням цілься в **1500 символів при 11pt**. Якщо треба густіший
текст, як у зразкових буклетах, — постав `"story_size": "8pt"` у `plot.json`.
Авто-підгонка все одно стисне кегль до 78%, якщо не влізе, і скаже про це
у звіті.


## Файли скіла

- `references/layout.md` — геометрія, шрифти, як усе влаштовано в CSS
- `references/midjourney.md` — як генерувати ілюстрації через GptProto  (і що робити без нього)
- `templates/plot.example.json` — заповнений приклад (детектив, 3 персонажі)
- `scripts/` — `validate_plot.py`, `build_booklet.py`, `palette.py`, `placeholder_art.py`
- `assets/booklet.css`, `assets/logos/*.png`
- `out/NAME/` — усі згенеровані буклети: `plot.json`, `art/`, PDF, HTML, прев'ю

## Друк

Дуплекс по довгій стороні, два згини в третину. Панель `ТИТУЛ` — права на
зовнішньому боці; після згину вона стає обкладинкою.
