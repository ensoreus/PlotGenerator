# Верстка

Геометрію знято з LizardCurse.pdf, Manufacture.pdf, HeartInChains.pdf,
FaithWithoutDoings.pdf.

## Аркуш

A4 landscape, 297×210 мм, 2 сторінки в одному PDF.

**Зовнішній бік** — `padding: 5.5mm`, три рівні колонки, проміжок 10.8 мм.
Панель виходить ≈88 мм завширшки — тобто третина 297 мм мінус поля.

**Внутрішній бік** — та сама сітка (`padding: 5.5mm`, три колонки, проміжок
10.8 мм), щоб поля і лінії згину збігались з зовнішнім боком: конфлікти в
першій колонці, сюжет займає дві інші (`grid-column: span 2`).

Порядок панелей зліва направо:

| бік | ліворуч | центр | праворуч |
|---|---|---|---|
| зовнішній | ФАКТИ | ПЕРСОНАЖІ | ТИТУЛ |
| внутрішній | КОНФЛІКТИ | СЮЖЕТ (на дві колонки) | |

## Шрифти

| Де | Шрифт |
|---|---|
| титульна панель (номер, назва, логлайн) | Hoefler Text |
| заголовки секцій ФАКТИ / ПЕРСОНАЖІ / КОНФЛІКТИ | Hoefler Text, трекінг 0.30em |
| решта тексту | Avenir Next |

Обидва — системні шрифти macOS, кирилицю мають. Запасні ланцюжки в CSS:
Didot → Baskerville → Georgia і Avenir → Helvetica Neue.

Базові кеглі: `--body-size: 10pt`, `--story-size: 11pt`, назва 22pt, заголовки 17pt.
Перевизначаються полями `body_size` / `story_size` у `plot.json`.

## Авто-підгонка

Скрипт у кінці HTML працює **на сторінці**, до того як Chrome друкує PDF —
через це вистачає одного запуску браузера:

1. Міряє заповненість кожної панелі: низ останньої дитини проти висоти
   контентного боксу. (`scrollHeight` не годиться — він ніколи не менший за
   `clientHeight`, тож недобір тексту з нього не видно.)
2. Панель переповнена → зменшує її множник кегля кроками по 2%, до 78%.
3. Панель конфліктів усе одно не влазить → знімає ілюстрацію (специфікація
   каже «якщо є місце») і повертає нормальний кегль.
4. Друкує звіт у `console.log`; `build_booklet.py` виловлює його зі stderr
   Chrome (`--enable-logging=stderr`) і показує людині.

Множники — CSS-змінні `--facts-scale`, `--chars-scale`, `--conflicts-scale`,
`--story-scale`, `--title-scale`. Їх можна зафіксувати вручну через
`"scales": {"story": 0.95}` у `plot.json`. Вимкнути підгонку — `--no-fit`.

## Ілюстрації

- Титульна: `aspect-ratio: 2/3`, рамка 1.2 мм кольором `--frame`,
  `min-height: 60mm`. Може трохи стиснутись, щоб дати місце довгій назві.
- Внутрішня: `aspect-ratio: 1/1`, рамка 1 мм, `min-height: 40mm`.
  Нижче цієї межі її просто знімають — краще без картинки, ніж смужка.
- Обидві `object-fit: cover`, тож картинку **обріже по краях**. Головне в
  композиції має бути по центру.

## Чому Chrome, а не reportlab

У системі немає reportlab, PIL, LaTeX, typst і wkhtmltopdf — тільки Python
stdlib, Chrome і ghostscript. HTML+CSS через `chrome --headless --print-to-pdf`
дає повний доступ до системних шрифтів і нормальну типографіку без залежностей.

Chrome на macOS часто не завершується сам після `--print-to-pdf`, тому
`to_pdf()` чекає, поки розмір файлу стабілізується, і гасить процес власноруч.
`--dump-dom` у цьому оточенні зависає намертво — не використовуй його.

Прев'ю робить ghostscript (`gs`), якщо він є; без нього PDF усе одно збереться,
просто не буде PNG для перевірки очима.
